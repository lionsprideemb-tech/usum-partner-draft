# USUM Partner Draft

A mobile-friendly two-player Pokémon Ultra Sun / Ultra Moon partner draft tool.

- Pokémon #001–#807 supported by USUM
- Important Alolan and type-changing forms included
- Two candidate picks per type
- Partner locks one choice
- Separate Player 1 / Player 2 boards
- Local save, JSON backup, shareable summary
